此地址尚未启用管理访问

在插件运行配置中，将 SETUP_PUBLIC_ORIGIN 设为浏览器地址栏中的协议、主机和端口，不含路径。使用 SETUP_ACCESS_KEY 设置 32–512 个字符的私密管理密钥。

Management access is unavailable at this address

Set SETUP_PUBLIC_ORIGIN to the browser origin (scheme, host and port, without a path). Set SETUP_ACCESS_KEY to a private key of 32–512 characters.

If CUBE only offers network, port and volume settings, put both settings in management.env in the dedicated data volume, one NAME=value per line. Mount the volume at /app/data, restart the add-on and reopen this page to unlock it.
